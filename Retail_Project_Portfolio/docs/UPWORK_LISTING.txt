TITLE
Retail Sales Analysis | Python Cleaning and Business Reporting

ROLE
Data analysis and reporting - academic portfolio example

DESCRIPTION
Turned 541,909 retail invoice lines into an auditable sales report using Python
and pandas. Separated gross sales from recorded cancellations, calculated net
value, ranked products by stock code, and analyzed monthly patterns, countries
and repeat purchasers. Delivered six summary tables, five charts and a cleaning
audit, supported by automated tests and independent checks. Public historical
data; this is a portfolio example, not a paid client engagement.

SKILLS
Python; pandas; Data Cleaning; Data Analysis; Data Visualization
